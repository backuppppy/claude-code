# web — סריקת אתר "הורים מחוברים" (conectedmmb)

האתר בנוי **Lovable / React / Supabase**. סרקנו את דף `/aut` והסברנו איך
מורידים את ה-JS bundle המקומפל לניתוח.

ה-bundle עצמו (תיקיית `dist/`, ~2MB) **לא נשמר כאן** — זה קוד צד-שלישי
(הקניין של האתר הנסרק), לא הקוד שלנו. אם צריך שוב: מורידים מחדש מהאתר.
