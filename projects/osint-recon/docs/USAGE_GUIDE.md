# 📖 מדריך שימוש — osint-recon

איך להשתמש בכלי לכל סוג חיפוש: מה מזינים, מה הוא עושה, מה מקבלים, וטיפים.

```bash
cd /root/claude-code-backup/projects/osint-recon
./osint <מטרה>                 # זיהוי אוטומטי של הסוג
./osint --type <סוג> <מטרה>    # כפיית סוג
```
פלט תמיד נשמר ב-`output/<מטרה>_<תאריך>/report.md` (+ `report.json`).

---

## 🔑 חוק הזהב: איך הכלי מזהה את סוג המטרה
הזיהוי האוטומטי עובד לפי **הפורמט** שאתה מקליד:

| מה שתקליד | יזוהה כ- | דוגמה |
|---|---|---|
| מכיל `@` | **email** | `dan@example.com` |
| `x.x.x.x` | **ip** | `8.8.8.8` |
| יש נקודה + סיומת אותיות | **domain** | `example.com` |
| מתחיל ב-`+` או ספרות/מקפים | **phone** | `+972501234567` |
| שתי מילים (עם רווח) | **person** | `"Israel Israeli"` |
| מילה אחת בלי נקודה | **username** | `johnsmith` |

> ⚠️ **הכלל הכי חשוב:** חיפוש **קובץ** לא מזוהה אוטומטית (שם קובץ עם רווח יזוהה כ"אדם"). לחיפוש קובץ **חובה** להשתמש ב-`--type file`.
> אם הזיהוי טועה — פשוט תכפה עם `--type`.

## 1️⃣ דומיין — `./osint example.com`
**מה עושה:** מיפוי מלא של דומיין (במקביל, ~3-5 דק').
- סאבדומיינים: crt.sh + subfinder + amass + hackertarget
- רשומות DNS (A/MX/NS/TXT), רישום (RDAP: registrar, תאריכים, nameservers)
- אימיילים ו-hosts (theHarvester)
- דומיינים דומים/פישינג (dnstwist)
- דפי login/admin (דורקים)
- 📄 **חיפוש קבצים עמוק** על הדומיין (ראה סעיף 7)
- עם מפתח: Hunter (אימיילים), VirusTotal (מוניטין)

**מתי:** בדיקת חברה/אתר, משטח תקיפה, bug bounty.

## 2️⃣ שם משתמש — `./osint johnsmith`
**מה עושה:** מאתר את אותו יוזרניים בכל הרשת.
- Sherlock (400+ אתרים) + Maigret (עוד יותר, עם ניתוח)
- socialscan (זמינות בפלטפורמות)
- פרופיל GitHub ציבורי (שם, חברה, אימייל, ריפו)
- דורקים סושיאל (טוויטר/אינסטגרם/רדיט/טלגרם...)
- 📄 חיפוש קבצים שמזכירים את השם

**טיפ:** מילה אחת בלי רווח. אם יש רווח → יזוהה כאדם.

## 3️⃣ אימייל — `./osint dan@example.com`
**מה עושה:** איפה האימייל רשום ומה דלף.
- holehe (100+ אתרים — איפה יש חשבון עם האימייל)
- socialscan (רישום בפלטפורמות)
- פרופיל Gravatar (אווטאר/שם/חשבונות מקושרים)
- דורקים + לינקים ל-HIBP/IntelX
- עם מפתח: HIBP (דליפות), EmailRep (מוניטין)

## 4️⃣ טלפון — `./osint "+972501234567"`
**מה עושה:** מזהויות ואזכורים של מספר.
- וריאציות פורמט (בינ"ל/מקומי/עם מקפים)
- דורקים (פייסבוק/לינקדאין/Truecaller/whocalled)
- לינקים ידניים (Truecaller, osint.industries, WhatsApp checkleaked)

**טיפ:** תמיד במרכאות, עדיף עם קידומת בינלאומית `+972`.

## 5️⃣ IP — `./osint 8.8.8.8`
**מה עושה:** מה רץ על הכתובת ומי הבעלים.
- Shodan InternetDB (פורטים+חולשות, חינם) + GreyNoise
- Geo/ASN, reverse DNS, WHOIS, netblock (RDAP)
- עם מפתח: Shodan מלא (שירותים+באנרים), VirusTotal, URLhaus

## 6️⃣ אדם (שם מלא) — `./osint "Israel Israeli"`
**מה עושה:** בניית פרופיל על אדם.
- פרופילים סושיאל + מקצועי (לינקדאין/פייסבוק/GitHub...)
- חדשות ואזכורים
- חיפוש תמונה הפוך (לינקים ל-Google Images/PimEyes)
- 📄 חיפוש מסמכים שמזכירים את השם

**טיפ:** שם מלא במרכאות. שם ייחודי = תוצאות טובות יותר.

## 7️⃣ 📄 חיפוש קובץ ייעודי — `./osint --type file "annual report 2023" --ext pdf`
**החזק ביותר לאיתור קבצים.** 5 שכבות:
1. `filetype:` ישיר
2. וריאציות שם (רווח / `_` / `-`)
3. ספריות פתוחות (`index of`)
4. שם מדויק + שיתופי ענן (Drive/Dropbox/Mega/Scribd)
5. עותקי Wayback מאומתים של הקבצים שנמצאו

**דוגמאות:**
```bash
./osint --type file "תקציב 2024"              # ברירת מחדל pdf
./osint --type file "salary data" --ext xlsx  # אקסל
./osint --type file "config backup" --ext sql # מסדי נתונים
```
סיומות שימושיות: `pdf docx xlsx csv pptx txt sql zip env conf bak`

## ⚙️ דגלים שימושיים
| דגל | מה עושה |
|---|---|
| `--type <סוג>` | כפיית סוג (domain/username/email/phone/ip/person/file) |
| `--ext <סיומת>` | סיומת קובץ (רק ל-`--type file`) |
| `--no-files` | דילוג על חיפוש הקבצים העמוק (מהיר יותר) |
| `-o <תיקייה>` | תיקיית פלט מותאמת |
