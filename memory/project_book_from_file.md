המשתמש כתב קובץ טקסט ענק במשך כמה שנים ורצה להפוך אותו לספר. בשיחה קודמת עזרתי לו לארגן את הקובץ לפי נושאים ולהפיק ממנו מבנה של ספר.

**Why:** פרויקט אישי — תיעוד שנים של כתיבה והפיכתה לתוכן מאורגן.

**How to apply:** אם המשתמש חוזר לנושא הקובץ/הספר, יש לי הקשר שמדובר בחומר אישי שנכתב לאורך שנים ושכבר עבדנו על מבנה לפי נושאים.
