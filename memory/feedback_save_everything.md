לתעד כל פרויקט, משימה, פתרון, או החלטה חשובה שנעשית במהלך כל שיחה — גם דברים קטנים.

**Why:** המשתמש חווה ניתוקים של שיחות ורוצה שנוכל להמשיך בדיוק מאיפה שעצרנו, בלי להתחיל מהתחלה.

**How to apply:** בסוף כל משימה משמעותית (או תוך כדי אם היא ארוכה), לכתוב זיכרון מתאים — project / feedback / user / reference — לפי הסוג המתאים.
