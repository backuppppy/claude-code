29/6/2026 — המשתמש ביקש את "מסילת ישרים סדר ויכוח" (גרסת הדיאלוג בין החכם לחסיד) כ-EPUB; הזכיר את אוצר החכמה.

ממצאים: גרסת הויכוח **אינה** קיימת כטקסט חופשי נקי ברשת (ויקיטקסט/ספריא = רק סדר הפרקים; אוצר = סריקות תמונה מאחורי התחברות). אבל בתיקיית ההורדות כבר היו כמה PDFים. המקור הטוב ביותר:
`/storage/emulated/0/Download/מסילת_ישרים_סדר_ויכוח_סדר_פרקים_משה_חיים_בן_יעקב_חי_לוצאטו_רמח''ל.pdf` (391 עמ', מהדורת מכון אופק) — יש לו **שכבת טקסט לא-מנוקדת נקייה** (המנוקד = OCR הרוס). עמ' 52–195 = "מסילת ישרים א" = סדר הויכוח; 196–322 = סדר הפרקים.

פתרון (בלי OCR): חילוץ עם PyMuPDF — גוף הטקסט בגודל פונט 18, תוויות דוברים 14/17 (זוהו ב-regex `אמ[רי] ה(חכם|חסיד)`), הערות שוליים בבלוק תחתון בפונט קטן (סוננו). פסקאות שוחזרו לפי קצה שמאלי (xl) של שורה. פרקים לפי הכותרת הרצה, ממופים לרשימה קנונית של 24 נושאים. ידוע: אשכולות מילים קצרות לפעמים הפוכים (פגם בקואורדינטות של שכבת הטקסט במקור — לא ניתן לתיקון גאומטרי) + שאריות סימני אפראט.

סקריפטים: `scratchpad/extract_my.py` + `build_epub.py` (EbookLib). תוצר: **`/storage/emulated/0/Download/מסילת_ישרים_-_סדר_ויכוח.epub`** (24 פרקים, ~172K תווים, RTL, תוויות דוברים מודגשות). כלים שהותקנו: tesseract 5.5 + heb (לא נדרש בסוף). קשור ל-[[feedback_save_everything]].
